question: |
  Write a SQL query to list all employees whose names start and end with the exact same character.
sampleData: |
  `employees` table: `name`
answer: |
  ```sql
  SELECT *
  FROM employees
  WHERE LOWER(LEFT(name, 1)) = LOWER(RIGHT(name, 1));
  ```
explanation: |
  - `LEFT(name, 1)` extracts first letter, `RIGHT(name, 1)` extracts last letter, converted to lowercase.
