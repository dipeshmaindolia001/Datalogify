question: |
  Write a recursive SQL query to compute the factorial of a given integer (e.g. 5!).
sampleData: |
  Input: N = 5. Target Output: 120.
answer: |
  ```sql
  WITH RECURSIVE Factorial(n, fact) AS (
      SELECT 1, 1
      UNION ALL
      SELECT n + 1, fact * (n + 1)
      FROM Factorial
      WHERE n < 5
  )
  SELECT fact FROM Factorial WHERE n = 5;
  ```
explanation: |
  - Base anchor case `(1, 1)`. Recursive member multiplies `fact * (n + 1)` until $n = 5$.
