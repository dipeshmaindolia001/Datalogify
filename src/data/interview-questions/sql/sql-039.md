question: |
  Write a SQL query to identify gaps in daily purchase dates for each customer.
sampleData: |
  `sales` table: `customer_id`, `purchase_date`
answer: |
  ```sql
  WITH OrderDates AS (
      SELECT customer_id, purchase_date,
             LAG(purchase_date) OVER (PARTITION BY customer_id ORDER BY purchase_date) AS prev_date
      FROM sales
  )
  SELECT customer_id, prev_date + INTERVAL '1 day' AS missing_date
  FROM OrderDates
  WHERE purchase_date > prev_date + INTERVAL '1 day';
  ```
explanation: |
  - Uses `LAG()` to inspect the previous purchase date.
  - Identifies rows where current date is more than 1 day after previous date.
