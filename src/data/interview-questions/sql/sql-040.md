question: |
  Write a SQL query to calculate the start date, end date, and duration of consecutive days where total daily sales exceeded $1,000.
sampleData: |
  `sales` table: `sale_date`, `amount`
answer: |
  ```sql
  WITH FlaggedSales AS (
      SELECT sale_date, amount,
             CASE WHEN amount > 1000 THEN 1 ELSE 0 END AS flag
      FROM sales
  ),
  Groups AS (
      SELECT sale_date, amount, flag,
             sale_date - (ROW_NUMBER() OVER (ORDER BY sale_date) * INTERVAL '1 day') AS grp
      FROM FlaggedSales
      WHERE flag = 1
  )
  SELECT MIN(sale_date) AS start_date, 
         MAX(sale_date) AS end_date, 
         COUNT(*) AS consecutive_days
  FROM Groups
  GROUP BY grp
  ORDER BY consecutive_days DESC;
  ```
explanation: |
  - Filters rows meeting the sales threshold (`flag = 1`).
  - Subtracting sequence row number from `sale_date` creates a constant group identifier for contiguous consecutive days.
