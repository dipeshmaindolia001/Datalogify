question: |
  Write a SQL query to find customer IDs whose total purchase spend exceeds $10,000.
sampleData: |
  `sales` table: `customer_id`, `amount`
answer: |
  ```sql
  SELECT customer_id, SUM(amount) AS total_amount
  FROM sales
  GROUP BY customer_id
  HAVING SUM(amount) > 10000;
  ```
explanation: |
  - Aggregates total spend per customer and filters spend `> 10000`.
