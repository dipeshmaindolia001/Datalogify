question: |
  Write a SQL query to find employee IDs who have worked in more than 3 different departments throughout their career.
sampleData: |
  `employee_department_history` table: `employee_id`, `department_id`
answer: |
  ```sql
  SELECT employee_id
  FROM employee_department_history
  GROUP BY employee_id
  HAVING COUNT(DISTINCT department_id) > 3;
  ```
explanation: |
  - Group by `employee_id` and filter `HAVING COUNT(DISTINCT department_id) > 3`.
