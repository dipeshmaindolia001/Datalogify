question: |
  Write a SQL query to rank salespeople by monthly sales amount, resetting the rank every month.
sampleData: |
  `sales` table: `salesperson_id`, `sale_date`, `amount`
answer: |
  ```sql
  WITH MonthlySales AS (
      SELECT salesperson_id, 
             DATE_TRUNC('month', sale_date) AS sale_month, 
             SUM(amount) AS total_sales
      FROM sales
      GROUP BY salesperson_id, DATE_TRUNC('month', sale_date)
  )
  SELECT salesperson_id, sale_month, total_sales,
         RANK() OVER (PARTITION BY sale_month ORDER BY total_sales DESC) AS monthly_rank
  FROM MonthlySales;
  ```
explanation: |
  - First CTE aggregates sales by salesperson and month using `DATE_TRUNC('month', sale_date)`.
  - `RANK() OVER (PARTITION BY sale_month ORDER BY total_sales DESC)` ranks salespeople independently within each month.
