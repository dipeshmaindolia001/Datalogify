question: |
  Write a SQL query to retrieve the N-th highest distinct salary from the employees table.
sampleData: |
  `employees` table: `salary`
answer: |
  ```sql
  SELECT DISTINCT salary
  FROM employees
  ORDER BY salary DESC
  LIMIT 1 OFFSET 2; -- Example for 3rd highest (N-1 = 2)
  ```
explanation: |
  - `DISTINCT salary` handles duplicate salary ties.
  - `ORDER BY salary DESC` sorts from highest to lowest.
  - `OFFSET N-1` skips the top $N-1$ salaries and `LIMIT 1` fetches the target $N$-th value.
