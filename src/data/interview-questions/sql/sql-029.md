question: |
  Write a SQL query to calculate the month-over-month percentage change in total sales for each product.
sampleData: |
  `sales` table: `product_id`, `sale_date`, `amount`
answer: |
  ```sql
  WITH MonthlySales AS (
      SELECT product_id, 
             DATE_TRUNC('month', sale_date) AS sale_month, 
             SUM(amount) AS total_sales
      FROM sales
      GROUP BY product_id, DATE_TRUNC('month', sale_date)
  )
  SELECT product_id, sale_month, total_sales,
         (total_sales - LAG(total_sales) OVER (PARTITION BY product_id ORDER BY sale_month)) * 100.0 / 
         LAG(total_sales) OVER (PARTITION BY product_id ORDER BY sale_month) AS pct_change
  FROM MonthlySales;
  ```
explanation: |
  - We calculate total monthly sales per product in a CTE.
  - Using `LAG(total_sales) OVER (PARTITION BY product_id ORDER BY sale_month)`, we retrieve the previous month's revenue.
  - Formula: `((Current - Previous) / Previous) * 100` gives the percentage growth.
