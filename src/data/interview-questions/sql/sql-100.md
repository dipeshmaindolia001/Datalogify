question: |
  Write a SQL query to identify employee IDs who logged consecutive daily attendance records.
sampleData: |
  `work_log` table: `employee_id`, `work_date`
answer: |
  ```sql
  WITH Attendance AS (
      SELECT employee_id, work_date,
             work_date - (ROW_NUMBER() OVER (PARTITION BY employee_id ORDER BY work_date) * INTERVAL '1 day') AS grp
      FROM work_log
  )
  SELECT employee_id, COUNT(*) AS consecutive_days
  FROM Attendance
  GROUP BY employee_id, grp
  HAVING COUNT(*) > 1;
  ```
explanation: |
  - Classic Gaps & Islands pattern to group consecutive attendance dates.
