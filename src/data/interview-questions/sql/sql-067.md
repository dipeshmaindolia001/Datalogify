question: |
  Write a SQL query to find customer IDs who have bought items exclusively from a single product category.
sampleData: |
  `sales` table: `customer_id`, `product_id`
  `products` table: `product_id`, `category_id`
answer: |
  ```sql
  SELECT customer_id
  FROM sales s
  JOIN products p ON s.product_id = p.product_id
  GROUP BY customer_id
  HAVING COUNT(DISTINCT p.category_id) = 1;
  ```
explanation: |
  - Joins sales to products to resolve category.
  - `HAVING COUNT(DISTINCT p.category_id) = 1` enforces single category purchasing.
