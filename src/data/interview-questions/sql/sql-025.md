question: |
  Write a SQL query to calculate a 3-row moving average of salaries ordered by hire date.
sampleData: |
  `employees` table:
  | id | name | hire_date | salary |
  |---|---|---|---|
  | 1 | Alice | 2024-01-01 | 50000 |
  | 2 | Bob | 2024-02-01 | 60000 |
  | 3 | Charlie | 2024-03-01 | 70000 |
answer: |
  ```sql
  SELECT name, hire_date, salary,
         AVG(salary) OVER (
             ORDER BY hire_date 
             ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
         ) AS moving_avg_salary
  FROM employees;
  ```
explanation: |
  - The window specification `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW` limits the window frame to the current row and the two preceding rows.
  - `AVG(salary)` computes the moving average over this 3-row sliding window.
