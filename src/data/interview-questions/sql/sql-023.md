question: |
  Write a SQL query to calculate the difference between each employee salary and the previous employee salary ordered by ID.
sampleData: |
  `employees` table:
  | id | name | salary |
  |---|---|---|
  | 1 | Alice | 50000 |
  | 2 | Bob | 65000 |
  | 3 | Charlie | 60000 |
answer: |
  ```sql
  SELECT name, salary,
         salary - LAG(salary) OVER (ORDER BY id) AS salary_diff
  FROM employees;
  ```
explanation: |
  - `LAG(salary) OVER (ORDER BY id)` accesses the salary value from the preceding row.
  - Subtracting the lagged salary yields the step difference.
