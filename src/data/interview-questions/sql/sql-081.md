question: |
  Write a SQL query to find the department ID and average salary for the department with the 2nd highest average salary.
sampleData: |
  `employees` table: `department_id`, `salary`
answer: |
  ```sql
  WITH AvgSalaries AS (
      SELECT department_id, AVG(salary) AS avg_salary
      FROM employees
      GROUP BY department_id
  ),
  RankedSalaries AS (
      SELECT department_id, avg_salary,
             DENSE_RANK() OVER (ORDER BY avg_salary DESC) AS rnk
      FROM AvgSalaries
  )
  SELECT department_id, avg_salary
  FROM RankedSalaries
  WHERE rnk = 2;
  ```
explanation: |
  - Ranks average department salaries descending using `DENSE_RANK()`.
