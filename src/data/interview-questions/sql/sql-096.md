question: |
  Write a recursive query to compute the total department budget managed under each manager (including all subordinate departments).
sampleData: |
  `departments` table: `id`, `manager_id`, `budget`
answer: |
  ```sql
  WITH RECURSIVE ManagerBudget AS (
      SELECT id, manager_id, budget
      FROM departments
      UNION ALL
      SELECT d.id, d.manager_id, mb.budget
      FROM departments d
      JOIN ManagerBudget mb ON d.manager_id = mb.id
  )
  SELECT manager_id, SUM(budget) AS total_budget
  FROM ManagerBudget
  GROUP BY manager_id;
  ```
explanation: |
  - Recursive CTE propagates department budgets up through management hierarchy.
