question: |
  Write a SQL query to find the department ID that has the highest number of employees.
sampleData: |
  `employees` table: `department_id`
answer: |
  ```sql
  SELECT department_id, COUNT(*) AS employee_count
  FROM employees
  GROUP BY department_id
  ORDER BY employee_count DESC
  LIMIT 1;
  ```
explanation: |
  - Group by department, sort headcount descending, and `LIMIT 1`.
