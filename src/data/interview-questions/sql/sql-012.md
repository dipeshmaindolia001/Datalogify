question: |
  Write a SQL query to find all department IDs that have more than 5 employees.
sampleData: |
  `employees` table:
  | id | name | department_id |
  |---|---|---|
  | 1 | Alice | 101 |
  | ... | ... | 101 |
answer: |
  ```sql
  SELECT department_id, COUNT(*) AS num_employees
  FROM employees
  GROUP BY department_id
  HAVING COUNT(*) > 5;
  ```
explanation: |
  - We group rows by `department_id` and use `COUNT(*)` to count the headcount per department.
  - We use the `HAVING` clause (which filters after grouping) to select only departments with more than 5 employees.
