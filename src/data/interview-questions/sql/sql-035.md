question: |
  Write a SQL query to retrieve the 2nd most recent order date for each customer.
sampleData: |
  `orders` table: `customer_id`, `order_date`
answer: |
  ```sql
  WITH RankedOrders AS (
      SELECT customer_id, order_date,
             ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date DESC) AS rn
      FROM orders
  )
  SELECT customer_id, order_date
  FROM RankedOrders
  WHERE rn = 2;
  ```
explanation: |
  - Ranks customer orders descending by date using `ROW_NUMBER()`.
  - Filters `WHERE rn = 2` to select the second newest order.
