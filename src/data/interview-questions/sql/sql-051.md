question: |
  Write a SQL query to find all employee IDs who have been assigned to a project for longer than 6 months.
sampleData: |
  `project_assignments` table:
  | employee_id | project_id | start_date | end_date |
  |---|---|---|---|
  | 101 | P1 | 2025-01-01 | 2025-09-01 |
  | 102 | P2 | 2025-03-01 | 2025-05-01 |
answer: |
  ```sql
  SELECT employee_id, project_id, start_date, end_date
  FROM project_assignments
  WHERE end_date - start_date > INTERVAL '6 months';
  ```
explanation: |
  - Date subtraction computes the duration interval between `start_date` and `end_date`.
  - Filtering for `> INTERVAL '6 months'` returns assignments exceeding 6 calendar months.
