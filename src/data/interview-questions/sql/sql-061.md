question: |
  Write a SQL query to find employees who were hired before their direct manager was hired.
sampleData: |
  `employees` table: `id`, `name`, `manager_id`, `hire_date`
answer: |
  ```sql
  SELECT e.name AS employee, m.name AS manager, e.hire_date, m.hire_date AS manager_hire_date
  FROM employees e
  JOIN employees m ON e.manager_id = m.id
  WHERE e.hire_date < m.hire_date;
  ```
explanation: |
  - Self join employee `e` to manager `m` on `manager_id = id`.
  - Filter `e.hire_date < m.hire_date`.
