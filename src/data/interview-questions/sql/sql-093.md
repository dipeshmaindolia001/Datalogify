question: |
  Write a SQL query to find the employee ID who claims the highest number of dependents.
sampleData: |
  `dependents` table: `employee_id`, `dependent_id`
answer: |
  ```sql
  SELECT employee_id, COUNT(*) AS dependent_count
  FROM dependents
  GROUP BY employee_id
  ORDER BY dependent_count DESC
  LIMIT 1;
  ```
explanation: |
  - Aggregates dependents by employee ID and returns maximum.
