question: |
  Write a SQL query to calculate the 90th percentile salary for each department using window functions.
sampleData: |
  `employees` table: `id`, `department_id`, `salary`
answer: |
  ```sql
  SELECT DISTINCT department_id,
         PERCENTILE_CONT(0.9) WITHIN GROUP (ORDER BY salary) OVER (PARTITION BY department_id) AS pct_90_salary
  FROM employees;
  ```
explanation: |
  - `PERCENTILE_CONT(0.9)` computes continuous percentile values (interpolating if needed).
  - `WITHIN GROUP (ORDER BY salary) OVER (PARTITION BY department_id)` calculates percentile values per department.
