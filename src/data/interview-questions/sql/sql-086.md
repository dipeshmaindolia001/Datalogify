question: |
  Write a SQL query to return the initial first order date for each customer.
sampleData: |
  `orders` table: `customer_id`, `order_date`
answer: |
  ```sql
  SELECT customer_id, MIN(order_date) AS first_order_date
  FROM orders
  GROUP BY customer_id;
  ```
explanation: |
  - Aggregates `MIN(order_date)` per `customer_id`.
