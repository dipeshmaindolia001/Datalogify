question: |
  Write a SQL query to retrieve all employees who joined the company within the last 6 months.
sampleData: |
  `employees` table:
  | id | name | join_date |
  |---|---|---|
  | 1 | Alice | 2026-01-15 |
  | 2 | Bob | 2024-05-10 |
answer: |
  ```sql
  SELECT *
  FROM employees
  WHERE join_date >= CURRENT_DATE - INTERVAL '6 months';
  ```
explanation: |
  - `CURRENT_DATE - INTERVAL '6 months'` calculates the exact timestamp 6 months prior to today.
  - Filtering for `join_date >= ...` retrieves all recent hires.
