question: |
  Write a SQL query to detect overlapping booking date ranges.
sampleData: |
  `bookings` table:
  | booking_id | start_date | end_date |
  |---|---|---|
  | 1 | 2026-01-01 | 2026-01-05 |
  | 2 | 2026-01-04 | 2026-01-08 |
answer: |
  ```sql
  SELECT b1.booking_id AS booking1, b2.booking_id AS booking2
  FROM bookings b1
  JOIN bookings b2 ON b1.booking_id < b2.booking_id
  WHERE b1.start_date <= b2.end_date
    AND b1.end_date >= b2.start_date;
  ```
explanation: |
  - Two intervals $[S_1, E_1]$ and $[S_2, E_2]$ overlap if and only if $S_1 le E_2$ and $E_1 ge S_2$.
  - The condition `b1.booking_id < b2.booking_id` prevents self-matching and duplicate inverted pairs.
