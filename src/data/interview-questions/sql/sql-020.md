question: |
  Write a SQL query to compute the cumulative distribution (CUME_DIST) of employee salaries.
sampleData: |
  `employees` table:
  | id | name | salary |
  |---|---|---|
  | 1 | Alice | 50000 |
  | 2 | Bob | 70000 |
  | 3 | Charlie | 100000 |
answer: |
  ```sql
  SELECT name, salary,
         CUME_DIST() OVER (ORDER BY salary) AS salary_cdf
  FROM employees;
  ```
explanation: |
  - `CUME_DIST()` calculates the relative position of a value in a dataset: (number of rows with values <= current row) / (total row count).
  - It returns values between 0 and 1, useful for quantile distributions.
