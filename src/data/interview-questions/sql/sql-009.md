question: |
  Write a SQL query to calculate the total revenue generated by each product.
sampleData: |
  `Sales` table:
  | sale_id | product_id | quantity | price |
  |---|---|---|---|
  | 1 | P1 | 2 | 50.00 |
  | 2 | P2 | 1 | 120.00 |
  | 3 | P1 | 3 | 50.00 |
answer: |
  ```sql
  SELECT product_id, SUM(quantity * price) AS total_revenue
  FROM Sales
  GROUP BY product_id;
  ```
explanation: |
  - For each row, we compute item revenue as `quantity * price`.
  - We group rows by `product_id` and apply the `SUM()` aggregate function to compute total revenue per product.
