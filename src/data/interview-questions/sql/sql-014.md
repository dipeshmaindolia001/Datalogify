question: |
  Write a SQL query to return all department names that currently have zero employees.
sampleData: |
  `departments` table:
  | department_id | department_name |
  |---|---|
  | 1 | IT |
  | 2 | Marketing |
  
  `employees` table:
  | id | name | department_id |
  |---|---|---|
  | 10 | Alice | 1 |
answer: |
  ```sql
  SELECT d.department_name
  FROM departments d
  LEFT JOIN employees e ON d.department_id = e.department_id
  WHERE e.id IS NULL;
  ```
explanation: |
  - Perform a `LEFT JOIN` from `departments` to `employees`.
  - Any department without assigned employees will produce `NULL` in employee columns.
  - We filter `WHERE e.id IS NULL` to isolate empty departments.
