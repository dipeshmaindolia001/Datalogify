question: |
  Write a SQL query to calculate the median salary of all employees.
sampleData: |
  `employees` table:
  | id | salary |
  |---|---|
  | 1 | 50000 |
  | 2 | 60000 |
  | 3 | 70000 |
  | 4 | 90000 |
answer: |
  ```sql
  WITH RankedSalaries AS (
      SELECT salary,
             ROW_NUMBER() OVER (ORDER BY salary) AS row_num,
             COUNT(*) OVER () AS total_count
      FROM employees
  )
  SELECT AVG(salary) AS median_salary
  FROM RankedSalaries
  WHERE row_num IN (FLOOR((total_count + 1) / 2.0), CEIL((total_count + 1) / 2.0));
  ```
explanation: |
  - We rank all salaries using `ROW_NUMBER() OVER (ORDER BY salary)` while counting the total rows with `COUNT(*) OVER ()`.
  - For an odd number of rows, the median is the middle value. For an even number of rows, the median is the average of the two middle values.
  - Using `FLOOR` and `CEIL` on `(total_count + 1) / 2.0` cleanly selects the middle 1 or 2 rows, and `AVG(salary)` computes the exact median.
