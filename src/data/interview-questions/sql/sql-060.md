question: |
  Write a SQL query to find the customer ID who experienced the longest gap (in days) between consecutive orders.
sampleData: |
  `orders` table: `customer_id`, `order_date`
answer: |
  ```sql
  WITH OrderedOrders AS (
      SELECT customer_id, order_date,
             LAG(order_date) OVER (PARTITION BY customer_id ORDER BY order_date) AS prev_order_date
      FROM orders
  ),
  Gaps AS (
      SELECT customer_id, order_date - prev_order_date AS gap_days
      FROM OrderedOrders
      WHERE prev_order_date IS NOT NULL
  )
  SELECT customer_id, MAX(gap_days) AS longest_gap
  FROM Gaps
  GROUP BY customer_id
  ORDER BY longest_gap DESC
  LIMIT 1;
  ```
explanation: |
  - Calculates date diff between current order and previous order using `LAG()`.
  - Group by customer and order by max gap descending.
