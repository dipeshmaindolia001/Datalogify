question: |
  Write a SQL query to find customer IDs who placed more than 1 purchase on the exact same date.
sampleData: |
  `sales` table: `customer_id`, `purchase_date`
answer: |
  ```sql
  SELECT customer_id, purchase_date, COUNT(*) AS purchase_count
  FROM sales
  GROUP BY customer_id, purchase_date
  HAVING COUNT(*) > 1;
  ```
explanation: |
  - Grouping by both `customer_id` and `purchase_date`.
  - `HAVING COUNT(*) > 1` filters out single daily purchases.
