question: |
  Write a recursive query to list all management ancestors (direct and indirect managers) for a given employee ID.
sampleData: |
  `employees` table: `id`, `name`, `manager_id`
answer: |
  ```sql
  WITH RECURSIVE Ancestors AS (
      SELECT id, name, manager_id
      FROM employees
      WHERE id = 101 -- Target employee ID
      UNION ALL
      SELECT e.id, e.name, e.manager_id
      FROM employees e
      JOIN Ancestors a ON e.id = a.manager_id
  )
  SELECT * FROM Ancestors WHERE id != 101;
  ```
explanation: |
  - Anchor selects target employee. Recursive step traverses upward matching `e.id = a.manager_id`.
