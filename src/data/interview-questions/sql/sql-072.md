question: |
  Write a window function query to detect duplicate rows across all table columns.
sampleData: |
  `your_table` table: `col1`, `col2`, `col3`
answer: |
  ```sql
  WITH RankedRows AS (
      SELECT *, COUNT(*) OVER (PARTITION BY col1, col2, col3) AS cnt
      FROM your_table
  )
  SELECT *
  FROM RankedRows
  WHERE cnt > 1;
  ```
explanation: |
  - `COUNT(*) OVER (PARTITION BY col1, col2, col3)` counts identical occurrences without collapsing rows.
