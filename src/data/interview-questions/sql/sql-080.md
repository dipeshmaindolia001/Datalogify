question: |
  Write a SQL query to list customers who placed at least one order in January but zero orders in February.
sampleData: |
  `orders` table: `customer_id`, `order_date`
answer: |
  ```sql
  WITH JanOrders AS (
      SELECT DISTINCT customer_id
      FROM orders
      WHERE EXTRACT(MONTH FROM order_date) = 1
  ),
  FebOrders AS (
      SELECT DISTINCT customer_id
      FROM orders
      WHERE EXTRACT(MONTH FROM order_date) = 2
  )
  SELECT customer_id
  FROM JanOrders
  WHERE customer_id NOT IN (SELECT customer_id FROM FebOrders);
  ```
explanation: |
  - Isolate January buyers and subtract February buyers via `NOT IN`.
