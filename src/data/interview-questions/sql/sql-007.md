question: |
  Write a SQL query to identify duplicate rows based on specified columns in a table.
sampleData: |
  `your_table` schema:
  | column1 | column2 | value |
  |---|---|---|
  | A | 100 | 50 |
  | A | 100 | 50 |
  | B | 200 | 30 |
  | C | 300 | 40 |
answer: |
  ```sql
  SELECT column1, column2, COUNT(*) AS duplicate_count
  FROM your_table
  GROUP BY column1, column2
  HAVING COUNT(*) > 1;
  ```
explanation: |
  - We group the table by the columns that define uniqueness (`column1`, `column2`).
  - `COUNT(*)` counts the number of occurrences for each combination of those columns.
  - The `HAVING COUNT(*) > 1` clause filters out groups that appear only once, leaving only the duplicate records.
