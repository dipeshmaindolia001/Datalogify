question: |
  Write a SQL query to find customers who placed at least one order in all 4 quarters of the current calendar year.
sampleData: |
  `sales` table: `customer_id`, `sale_date`, `amount`
answer: |
  ```sql
  SELECT customer_id
  FROM sales
  WHERE EXTRACT(YEAR FROM sale_date) = EXTRACT(YEAR FROM CURRENT_DATE)
  GROUP BY customer_id
  HAVING COUNT(DISTINCT EXTRACT(QUARTER FROM sale_date)) = 4;
  ```
explanation: |
  - Filters current year transactions.
  - Groups by `customer_id` and verifies distinct quarter count equals 4.
