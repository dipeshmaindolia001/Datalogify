question: |
  Write a SQL query to retrieve the single most recent order record for each customer.
sampleData: |
  `sales` table:
  | sale_id | customer_id | purchase_date | amount |
  |---|---|---|---|
  | 10 | 1 | 2026-01-10 | 100 |
  | 11 | 1 | 2026-02-15 | 250 |
  | 12 | 2 | 2026-01-20 | 150 |
answer: |
  ```sql
  WITH RankedSales AS (
      SELECT *,
             ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY purchase_date DESC) AS rn
      FROM sales
  )
  SELECT *
  FROM RankedSales
  WHERE rn = 1;
  ```
explanation: |
  - `ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY purchase_date DESC)` assigns sequential rank numbers starting at 1 for the newest purchase per customer.
  - Filtering `WHERE rn = 1` isolates each customer's latest order.
