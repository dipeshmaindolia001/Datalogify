question: |
  Write a SQL query to find all active employees who have never submitted any leave request.
sampleData: |
  `employees` table: `id`, `name`
  `leaves` table: `leave_id`, `employee_id`
answer: |
  ```sql
  SELECT e.*
  FROM employees e
  LEFT JOIN leaves l ON e.id = l.employee_id
  WHERE l.leave_id IS NULL;
  ```
explanation: |
  - `LEFT JOIN` leaves table and filter `WHERE l.leave_id IS NULL`.
