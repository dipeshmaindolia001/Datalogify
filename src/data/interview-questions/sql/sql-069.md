question: |
  Write a SQL query to retrieve top N highest-spending customers.
sampleData: |
  `sales` table: `customer_id`, `amount`
answer: |
  ```sql
  SELECT customer_id, SUM(amount) AS total_sales
  FROM sales
  GROUP BY customer_id
  ORDER BY total_sales DESC
  LIMIT 5; -- Example for Top 5 customers
  ```
explanation: |
  - Groups spend by customer, sorts descending, and limits results.
