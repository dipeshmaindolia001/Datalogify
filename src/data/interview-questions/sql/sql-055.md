question: |
  Write a SQL query to find the 2nd highest salary in each department using correlated subqueries without using window functions.
sampleData: |
  `employees` table: `id`, `department_id`, `salary`
answer: |
  ```sql
  SELECT department_id, MAX(salary) AS second_highest_salary
  FROM employees e1
  WHERE salary < (
      SELECT MAX(salary)
      FROM employees e2
      WHERE e2.department_id = e1.department_id
  )
  GROUP BY department_id;
  ```
explanation: |
  - The correlated subquery calculates max salary per department.
  - Outer query finds max salary strictly lower than department top salary.
