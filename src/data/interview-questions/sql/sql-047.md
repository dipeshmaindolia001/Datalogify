question: |
  Write a SQL query to find employees whose salary is strictly above their department average but strictly below the company-wide average.
sampleData: |
  `employees` table: `id`, `name`, `department_id`, `salary`
answer: |
  ```sql
  SELECT *
  FROM employees e
  WHERE salary > (
      SELECT AVG(salary) 
      FROM employees 
      WHERE department_id = e.department_id
  )
  AND salary < (SELECT AVG(salary) FROM employees);
  ```
explanation: |
  - First subquery computes the correlated department average.
  - Second subquery computes the global scalar company average.
