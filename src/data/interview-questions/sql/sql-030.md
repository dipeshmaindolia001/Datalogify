question: |
  Write a recursive query to detect circular hierarchy references (e.g. Employee A manages B who manages A).
sampleData: |
  `employees` table: `id`, `name`, `manager_id`
answer: |
  ```sql
  WITH RECURSIVE mgr_path (id, manager_id, path) AS (
      SELECT id, manager_id, ARRAY[id]
      FROM employees
      WHERE manager_id IS NOT NULL
      UNION ALL
      SELECT e.id, e.manager_id, path || e.id
      FROM employees e
      JOIN mgr_path mp ON e.manager_id = mp.id
      WHERE NOT e.id = ANY(path)
  )
  SELECT DISTINCT id
  FROM mgr_path
  WHERE id = ANY(path);
  ```
explanation: |
  - Tracks an array `path` of visited IDs in the hierarchy chain.
  - Prevents infinite loops using `WHERE NOT e.id = ANY(path)`.
  - Any record where `id = ANY(path)` indicates a circular dependency bug.
