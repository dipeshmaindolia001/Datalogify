question: |
  Write a SQL query to find products whose sales occurred exclusively within the current calendar month.
sampleData: |
  `sales` table: `product_id`, `sale_date`
answer: |
  ```sql
  SELECT product_id
  FROM sales
  GROUP BY product_id
  HAVING MAX(sale_date) >= DATE_TRUNC('month', CURRENT_DATE)
     AND MIN(sale_date) >= DATE_TRUNC('month', CURRENT_DATE);
  ```
explanation: |
  - Verifies both minimum and maximum transaction dates fall within current month start.
