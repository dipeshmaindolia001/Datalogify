question: |
  Write a SQL query to find customers who have purchased products from every single product category available.
sampleData: |
  `sales` table: `customer_id`, `category_id`
answer: |
  ```sql
  SELECT customer_id
  FROM sales
  GROUP BY customer_id
  HAVING COUNT(DISTINCT category_id) = (SELECT COUNT(DISTINCT category_id) FROM sales);
  ```
explanation: |
  - `COUNT(DISTINCT category_id)` counts the distinct categories purchased by each customer.
  - Comparing this count to the total count of distinct categories in the store (`SELECT COUNT(DISTINCT category_id) FROM sales`) enforces relational division.
