question: |
  Write a SQL query to count the number of male and female employees in each department.
sampleData: |
  `employees` table:
  | id | name | gender | department_id |
  |---|---|---|---|
  | 1 | Alice | F | 10 |
  | 2 | Bob | M | 10 |
  | 3 | Charlie | M | 10 |
answer: |
  ```sql
  SELECT department_id,
         COUNT(CASE WHEN gender = 'M' THEN 1 END) AS male_count,
         COUNT(CASE WHEN gender = 'F' THEN 1 END) AS female_count
  FROM employees
  GROUP BY department_id;
  ```
explanation: |
  - Using `CASE WHEN` inside `COUNT()` evaluates to `1` when the condition is met and `NULL` otherwise.
  - Since aggregate functions ignore `NULL`, this counts occurrences conditionally per group.
