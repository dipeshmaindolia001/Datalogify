question: |
  Write a SQL query to find all employees who do not report to any manager (top executives).
sampleData: |
  `employees` table: `id`, `name`, `manager_id`
answer: |
  ```sql
  SELECT *
  FROM employees
  WHERE manager_id IS NULL;
  ```
explanation: |
  - Filters `WHERE manager_id IS NULL`.
