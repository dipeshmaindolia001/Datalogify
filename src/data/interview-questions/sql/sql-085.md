question: |
  Write a SQL query to find employees who have had zero salary adjustment records in the past 2 years.
sampleData: |
  `employees` table: `id`, `name`
  `salary_history` table: `employee_id`, `change_date`
answer: |
  ```sql
  SELECT e.*
  FROM employees e
  LEFT JOIN salary_history sh ON e.id = sh.employee_id 
       AND sh.change_date >= CURRENT_DATE - INTERVAL '2 years'
  WHERE sh.employee_id IS NULL;
  ```
explanation: |
  - `LEFT JOIN` salary changes in recent 2-year window and filter `WHERE sh.employee_id IS NULL`.
