question: |
  Write a SQL query to find the department ID that has recorded the highest total number of employee promotions.
sampleData: |
  `promotions` table: `employee_id`, `promotion_date`
  `employees` table: `id`, `department_id`
answer: |
  ```sql
  SELECT e.department_id, COUNT(*) AS promotion_count
  FROM promotions p
  JOIN employees e ON p.employee_id = e.id
  GROUP BY e.department_id
  ORDER BY promotion_count DESC
  LIMIT 1;
  ```
explanation: |
  - Join promotions to employee records to attribute promotions to departments.
  - Group by department and sort descending with `LIMIT 1` to fetch top department.
