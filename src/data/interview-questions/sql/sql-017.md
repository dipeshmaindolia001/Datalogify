question: |
  Write a SQL query to calculate the longest consecutive streak of daily logins for each user.
sampleData: |
  `user_logins` table:
  | user_id | login_date |
  |---|---|
  | 1 | 2026-01-01 |
  | 1 | 2026-01-02 |
  | 1 | 2026-01-03 |
  | 1 | 2026-01-05 |
answer: |
  ```sql
  WITH login_dates AS (
      SELECT user_id, login_date,
             login_date - (ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY login_date) * INTERVAL '1 day') AS grp
      FROM user_logins
  )
  SELECT user_id, 
         COUNT(*) AS streak_length,
         MIN(login_date) AS start_date, 
         MAX(login_date) AS end_date
  FROM login_dates
  GROUP BY user_id, grp
  ORDER BY streak_length DESC;
  ```
explanation: |
  - Classic **Gaps & Islands** problem pattern.
  - Subtracting `ROW_NUMBER() * INTERVAL '1 day'` from `login_date` produces a constant grouped date (`grp`) for contiguous consecutive daily dates.
  - Grouping by `user_id` and `grp` lets us count streak lengths with `COUNT(*)`.
