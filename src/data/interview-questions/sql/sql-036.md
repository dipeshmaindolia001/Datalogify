question: |
  Write a SQL query to return employees in the top 10% highest salary tier within their department.
sampleData: |
  `employees` table: `id`, `department_id`, `salary`
answer: |
  ```sql
  WITH RankedEmployees AS (
      SELECT e.*,
             NTILE(10) OVER (PARTITION BY department_id ORDER BY salary DESC) AS decile
      FROM employees e
  )
  SELECT *
  FROM RankedEmployees
  WHERE decile = 1;
  ```
explanation: |
  - `NTILE(10)` divides partitioned department rows into 10 equal percentile buckets (deciles).
  - `decile = 1` represents the top 10% highest salaries.
