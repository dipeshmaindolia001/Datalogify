question: |
  Write a SQL query to retrieve all employees whose salary falls strictly between the 25th percentile (Q1) and 75th percentile (Q3) of company salaries.
sampleData: |
  `employees` table: `id`, `name`, `salary`
answer: |
  ```sql
  WITH Percentiles AS (
      SELECT
          PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY salary) AS p25,
          PERCENTILE_CONT(0.75) WITHIN GROUP (ORDER BY salary) AS p75
      FROM employees
  )
  SELECT e.*
  FROM employees e, Percentiles p
  WHERE e.salary BETWEEN p.p25 AND p.p75;
  ```
explanation: |
  - `PERCENTILE_CONT(0.25)` and `PERCENTILE_CONT(0.75)` calculate Q1 and Q3.
  - Joining the CTE allows filtering rows in the interquartile range.
