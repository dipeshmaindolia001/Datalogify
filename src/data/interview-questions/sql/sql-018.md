question: |
  Write a recursive query to find the complete organizational hierarchy reporting chain and level for every employee starting from top management.
sampleData: |
  `employees` table:
  | id | name | manager_id |
  |---|---|---|
  | 1 | CEO | NULL |
  | 2 | VP Eng | 1 |
  | 3 | Dev Lead | 2 |
answer: |
  ```sql
  WITH RECURSIVE reporting_chain AS (
      SELECT id, name, manager_id, 1 AS level
      FROM employees
      WHERE manager_id IS NULL
      UNION ALL
      SELECT e.id, e.name, e.manager_id, rc.level + 1
      FROM employees e
      JOIN reporting_chain rc ON e.manager_id = rc.id
  )
  SELECT * FROM reporting_chain ORDER BY level, id;
  ```
explanation: |
  - The anchor query selects top-level executives (`WHERE manager_id IS NULL`) with `level = 1`.
  - The recursive member joins `employees` to `reporting_chain` on `e.manager_id = rc.id`, incrementing `level + 1` at each step.
