question: |
  Write a SQL query to find the department ID that has the lowest average salary.
sampleData: |
  `employees` table: `department_id`, `salary`
answer: |
  ```sql
  SELECT department_id, AVG(salary) AS avg_salary
  FROM employees
  GROUP BY department_id
  ORDER BY avg_salary ASC
  LIMIT 1;
  ```
explanation: |
  - Aggregates average salary per department and sorts ascending.
