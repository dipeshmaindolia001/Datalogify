question: |
  Write a SQL query to find all numbers that appear at least three times consecutively in a table of logs.
sampleData: |
  `Logs` table:
  | Id | Num |
  |---|---|
  | 1 | 1 |
  | 2 | 1 |
  | 3 | 1 |
  | 4 | 2 |
  | 5 | 1 |
  | 6 | 2 |
  | 7 | 2 |
answer: |
  Using `LEAD` and `LAG`:
  ```sql
  SELECT DISTINCT Num AS ConsecutiveNums
  FROM (
      SELECT 
          Num,
          LAG(Num, 1) OVER (ORDER BY Id) AS prev_num,
          LEAD(Num, 1) OVER (ORDER BY Id) AS next_num
      FROM Logs
  ) t
  WHERE Num = prev_num AND Num = next_num;
  ```

  Using the Group Island (Difference in Row Numbers) technique:
  ```sql
  WITH GroupedLogs AS (
      SELECT 
          Num,
          Id - ROW_NUMBER() OVER (PARTITION BY Num ORDER BY Id) AS rnk_diff
      FROM Logs
  )
  SELECT DISTINCT Num AS ConsecutiveNums
  FROM GroupedLogs
  GROUP BY Num, rnk_diff
  HAVING COUNT(*) >= 3;
  ```
explanation: |
  - In the `LEAD`/`LAG` approach, we fetch the previous row's number and the next row's number, comparing them to the current row. If they are equal, then it is a consecutive streak of 3.
  - In the Row Number Difference approach, subtracting a sequential sequence (`ROW_NUMBER()`) from the sorted row IDs (`Id`) yields a constant difference value (`rnk_diff`) for consecutive matching numbers. Grouping by the number and this difference lets us easily count the length of the streak.
followUp: |
  How would you extend the second query to find login streaks of at least 5 consecutive days?
  - You would parse dates instead of IDs, but subtract the `ROW_NUMBER()` (converted to date intervals) from the login dates to create the group identifier. Then filter by `HAVING COUNT(DISTINCT login_date) >= 5`.
