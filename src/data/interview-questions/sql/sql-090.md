question: |
  Write a SQL query to find employee IDs who have been assigned to every project in the system.
sampleData: |
  `project_assignments` table: `employee_id`, `project_id`
  `projects` table: `project_id`
answer: |
  ```sql
  SELECT employee_id
  FROM project_assignments
  GROUP BY employee_id
  HAVING COUNT(DISTINCT project_id) = (SELECT COUNT(*) FROM projects);
  ```
explanation: |
  - Enforces relational division by matching employee distinct project count to total active project count.
