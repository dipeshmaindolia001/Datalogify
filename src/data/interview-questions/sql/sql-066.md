question: |
  Write a SQL query to calculate running cumulative count of orders for each customer ordered by order date.
sampleData: |
  `orders` table: `customer_id`, `order_date`
answer: |
  ```sql
  SELECT customer_id, order_date,
         COUNT(*) OVER (PARTITION BY customer_id ORDER BY order_date) AS cumulative_orders
  FROM orders;
  ```
explanation: |
  - `COUNT(*) OVER (PARTITION BY customer_id ORDER BY order_date)` accumulates running transaction counts.
