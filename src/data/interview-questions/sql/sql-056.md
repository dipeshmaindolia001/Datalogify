question: |
  Write a SQL query to unpivot quarterly sales columns (Q1_sales, Q2_sales, Q3_sales, Q4_sales) into individual rows per product.
sampleData: |
  `sales_data` table: `product_id`, `Q1_sales`, `Q2_sales`, `Q3_sales`, `Q4_sales`
answer: |
  ```sql
  SELECT product_id, 'Q1' AS quarter, Q1_sales AS sales FROM sales_data
  UNION ALL
  SELECT product_id, 'Q2', Q2_sales FROM sales_data
  UNION ALL
  SELECT product_id, 'Q3', Q3_sales FROM sales_data
  UNION ALL
  SELECT product_id, 'Q4', Q4_sales FROM sales_data;
  ```
explanation: |
  - Uses `UNION ALL` to stack quarterly columns into row-oriented dataset.
