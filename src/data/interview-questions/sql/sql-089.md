question: |
  Write a SQL query to calculate the total span in days between a customer's earliest order and latest order.
sampleData: |
  `orders` table: `customer_id`, `order_date`
answer: |
  ```sql
  SELECT customer_id, MAX(order_date) - MIN(order_date) AS days_between
  FROM orders
  GROUP BY customer_id;
  ```
explanation: |
  - Computes difference `MAX(order_date) - MIN(order_date)` per customer.
