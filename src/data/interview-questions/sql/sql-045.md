question: |
  Write a SQL query to pivot monthly sales totals into individual columns (Jan, Feb, ..., Dec) for each product.
sampleData: |
  `sales` table: `product_id`, `sale_date`, `amount`
answer: |
  ```sql
  SELECT product_id,
         SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 1 THEN amount ELSE 0 END) AS Jan,
         SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 2 THEN amount ELSE 0 END) AS Feb,
         SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 3 THEN amount ELSE 0 END) AS Mar,
         SUM(CASE WHEN EXTRACT(MONTH FROM sale_date) = 12 THEN amount ELSE 0 END) AS Dec
  FROM sales
  GROUP BY product_id;
  ```
explanation: |
  - Standard conditional aggregation strategy to pivot rows into columns across RDBMS engines without relying on vendor-specific PIVOT syntax.
