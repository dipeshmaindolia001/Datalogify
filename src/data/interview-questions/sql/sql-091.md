question: |
  Write a SQL query to list order counts per day across a full continuous date range, including zero count for days without orders.
sampleData: |
  `orders` table: `order_id`, `order_date`
answer: |
  ```sql
  WITH Calendar AS (
      SELECT generate_series(MIN(order_date), MAX(order_date), INTERVAL '1 day') AS day
      FROM orders
  )
  SELECT c.day, COUNT(o.order_id) AS order_count
  FROM Calendar c
  LEFT JOIN orders o ON c.day = o.order_date
  GROUP BY c.day
  ORDER BY c.day;
  ```
explanation: |
  - Generates continuous dates in CTE and `LEFT JOIN` orders table to count daily orders.
