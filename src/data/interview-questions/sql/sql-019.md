question: |
  Write a SQL query to identify missing IDs (gaps) in a sequence of employee IDs.
sampleData: |
  `employees` table:
  | id | name |
  |---|---|
  | 1 | Alice |
  | 2 | Bob |
  | 4 | Dave |
answer: |
  ```sql
  SELECT (id + 1) AS missing_id
  FROM employees e1
  WHERE NOT EXISTS (
      SELECT 1 FROM employees e2 WHERE e2.id = e1.id + 1
  ) AND id < (SELECT MAX(id) FROM employees)
  ORDER BY missing_id;
  ```
explanation: |
  - For every `id`, we check if `id + 1` exists in the table.
  - Using `NOT EXISTS` finds IDs where the next immediate integer is missing from the table sequence.
