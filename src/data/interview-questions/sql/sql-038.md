question: |
  Write a SQL query to calculate the cumulative percentage contribution of sales per product sorted descending.
sampleData: |
  `sales` table: `product_id`, `sale_amount`
answer: |
  ```sql
  SELECT product_id, sale_amount,
         SUM(sale_amount) OVER (ORDER BY sale_amount DESC) * 100.0 / SUM(sale_amount) OVER () AS cumulative_pct
  FROM sales;
  ```
explanation: |
  - `SUM(sale_amount) OVER (ORDER BY ... DESC)` computes running total of top sales.
  - `SUM(sale_amount) OVER ()` calculates grand total across all rows.
  - Dividing running total by grand total yields cumulative percentage (Pareto principle analysis).
