question: |
  Write a SQL query to compare two identical schema tables and return rows where values differ in any column.
sampleData: |
  `table1` and `table2` schemas: `id`, `col1`, `col2`
answer: |
  ```sql
  SELECT *
  FROM table1 t1
  FULL OUTER JOIN table2 t2 ON t1.id = t2.id
  WHERE t1.col1 IS DISTINCT FROM t2.col1
     OR t1.col2 IS DISTINCT FROM t2.col2;
  ```
explanation: |
  - A `FULL OUTER JOIN` combines all rows from both tables.
  - `IS DISTINCT FROM` handles NULL values safely (treating NULL vs non-NULL as a difference and NULL vs NULL as identical).
