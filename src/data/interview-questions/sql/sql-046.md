question: |
  Write a SQL query to find all products that have never been purchased.
sampleData: |
  `products` table: `product_id`, `product_name`
  `sales` table: `sale_id`, `product_id`
answer: |
  ```sql
  SELECT p.product_id, p.product_name
  FROM products p
  LEFT JOIN sales s ON p.product_id = s.product_id
  WHERE s.sale_id IS NULL;
  ```
explanation: |
  - `LEFT JOIN` from `products` to `sales`.
  - Products with no sales records produce `NULL` values in `s.sale_id`.
