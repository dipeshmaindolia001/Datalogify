question: |
  Write a SQL query to find the employee(s) who earn the top salary in their respective department.
sampleData: |
  `employees` table: `id`, `name`, `department_id`, `salary`
answer: |
  ```sql
  WITH DeptMax AS (
      SELECT department_id, MAX(salary) AS max_salary
      FROM employees
      GROUP BY department_id
  )
  SELECT e.*
  FROM employees e
  JOIN DeptMax d ON e.department_id = d.department_id AND e.salary = d.max_salary;
  ```
explanation: |
  - CTE finds department max salary.
  - Join back to `employees` on department and salary to return matching records.
