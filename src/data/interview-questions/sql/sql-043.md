question: |
  Write a SQL query to detect overlapping work shifts assigned to the same employee.
sampleData: |
  `shifts` table: `employee_id`, `shift_id`, `start_time`, `end_time`
answer: |
  ```sql
  SELECT s1.employee_id, s1.shift_id AS shift1, s2.shift_id AS shift2
  FROM shifts s1
  JOIN shifts s2 ON s1.employee_id = s2.employee_id AND s1.shift_id < s2.shift_id
  WHERE s1.start_time < s2.end_time AND s1.end_time > s2.start_time;
  ```
explanation: |
  - Self-joins shifts table on matching `employee_id` and distinct shift IDs.
  - Time condition `s1.start_time < s2.end_time AND s1.end_time > s2.start_time` checks for overlapping time spans.
