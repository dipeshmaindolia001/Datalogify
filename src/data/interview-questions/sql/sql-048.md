question: |
  Write a SQL query to calculate the overall average order count per customer along with standard deviation.
sampleData: |
  `orders` table: `order_id`, `customer_id`
answer: |
  ```sql
  WITH CustomerOrders AS (
      SELECT customer_id, COUNT(*) AS order_count
      FROM orders
      GROUP BY customer_id
  )
  SELECT AVG(order_count) AS avg_orders,
         STDDEV(order_count) AS stddev_orders
  FROM CustomerOrders;
  ```
explanation: |
  - CTE computes order totals per customer.
  - Outer query computes population/sample `AVG` and `STDDEV`.
