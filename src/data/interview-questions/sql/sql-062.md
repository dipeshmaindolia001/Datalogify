question: |
  Write a SQL query to list department IDs whose average salary is strictly greater than company average salary.
sampleData: |
  `employees` table: `department_id`, `salary`
answer: |
  ```sql
  SELECT department_id, AVG(salary) AS avg_salary
  FROM employees
  GROUP BY department_id
  HAVING AVG(salary) > (SELECT AVG(salary) FROM employees);
  ```
explanation: |
  - Subquery computes scalar global average.
  - `HAVING` clause filters department groupings exceeding global mean.
