question: |
  Write a SQL query to compute average employee salary grouped by hire year.
sampleData: |
  `employees` table: `hire_date`, `salary`
answer: |
  ```sql
  SELECT EXTRACT(YEAR FROM hire_date) AS hire_year, AVG(salary) AS avg_salary
  FROM employees
  GROUP BY EXTRACT(YEAR FROM hire_date)
  ORDER BY hire_year;
  ```
explanation: |
  - Extracts year component from hire date and computes average salary per group.
