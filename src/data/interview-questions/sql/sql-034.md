question: |
  Write a SQL query to count hires by year and compute a cumulative running total of total hires over time.
sampleData: |
  `employees` table: `id`, `hire_date`
answer: |
  ```sql
  WITH YearlyHires AS (
      SELECT EXTRACT(YEAR FROM hire_date) AS join_year, 
             COUNT(*) AS yearly_hires
      FROM employees
      GROUP BY EXTRACT(YEAR FROM hire_date)
  )
  SELECT join_year, yearly_hires,
         SUM(yearly_hires) OVER (ORDER BY join_year) AS running_total_hires
  FROM YearlyHires
  ORDER BY join_year;
  ```
explanation: |
  - Group by hire year to get annual counts.
  - `SUM(yearly_hires) OVER (ORDER BY join_year)` aggregates cumulative workforce growth.
