question: |
  Write a SQL query to identify the top-spending customer for each calendar year.
sampleData: |
  `sales` table: `customer_id`, `sale_date`, `amount`
answer: |
  ```sql
  WITH YearlySales AS (
      SELECT customer_id, 
             EXTRACT(YEAR FROM sale_date) AS year, 
             SUM(amount) AS total_amount
      FROM sales
      GROUP BY customer_id, EXTRACT(YEAR FROM sale_date)
  ),
  RankedSales AS (
      SELECT *, RANK() OVER (PARTITION BY year ORDER BY total_amount DESC) AS rnk
      FROM YearlySales
  )
  SELECT customer_id, year, total_amount
  FROM RankedSales
  WHERE rnk = 1;
  ```
explanation: |
  - Ranks annual total customer spend descending within each year.
