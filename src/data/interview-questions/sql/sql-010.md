question: |
  Write a SQL query to find customers who placed orders but never returned any product.
sampleData: |
  `Customers` table:
  | customer_id | name |
  |---|---|
  | 1 | Alice |
  | 2 | Bob |
  | 3 | Charlie |
  
  `Orders` table:
  | order_id | customer_id |
  |---|---|
  | 101 | 1 |
  | 102 | 2 |
  | 103 | 3 |
  
  `Returns` table:
  | return_id | customer_id |
  |---|---|
  | 501 | 2 |
answer: |
  ```sql
  SELECT DISTINCT c.customer_id, c.name
  FROM Customers c
  JOIN Orders o ON c.customer_id = o.customer_id
  WHERE c.customer_id NOT IN (
      SELECT customer_id 
      FROM Returns 
      WHERE customer_id IS NOT NULL
  );
  ```
explanation: |
  - We join `Customers` and `Orders` to ensure we only evaluate customers who made at least one purchase.
  - The subquery `SELECT customer_id FROM Returns` retrieves all customer IDs associated with returns.
  - Using `WHERE c.customer_id NOT IN (...)` excludes any customer who has a return record.
