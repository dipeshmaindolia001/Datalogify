question: |
  Write a SQL query to find customers who placed orders in the last 30 days and had zero orders prior to that window.
sampleData: |
  `orders` table: `customer_id`, `order_date`
answer: |
  ```sql
  SELECT DISTINCT customer_id
  FROM orders
  WHERE order_date >= CURRENT_DATE - INTERVAL '30 days'
    AND customer_id NOT IN (
        SELECT DISTINCT customer_id
        FROM orders
        WHERE order_date < CURRENT_DATE - INTERVAL '30 days'
    );
  ```
explanation: |
  - Isolate active users in recent 30-day window and exclude any user with older order records.
