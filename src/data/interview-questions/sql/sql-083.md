question: |
  Write a recursive query to list all direct and indirect subordinates of a specified manager ID.
sampleData: |
  `employees` table: `id`, `name`, `manager_id`
answer: |
  ```sql
  WITH RECURSIVE Subordinates AS (
      SELECT id, name, manager_id
      FROM employees
      WHERE manager_id = 100 -- Starting manager ID
      UNION ALL
      SELECT e.id, e.name, e.manager_id
      FROM employees e
      INNER JOIN Subordinates s ON e.manager_id = s.id
  )
  SELECT * FROM Subordinates;
  ```
explanation: |
  - Anchor query selects direct reports. Recursive member joins downwards.
