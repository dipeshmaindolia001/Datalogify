question: |
  Write a SQL query to calculate a cumulative running total of salaries for employees partitioned by department.
sampleData: |
  `employees` table:
  | id | name | department_id | salary |
  |---|---|---|---|
  | 1 | Alice | 10 | 50000 |
  | 2 | Bob | 10 | 60000 |
  | 3 | Charlie | 20 | 70000 |
answer: |
  ```sql
  SELECT name, department_id, salary,
         SUM(salary) OVER (PARTITION BY department_id ORDER BY id) AS running_total
  FROM employees;
  ```
explanation: |
  - `SUM(salary) OVER (...)` is an aggregate window function.
  - `PARTITION BY department_id` resets the running total calculation for each department.
  - `ORDER BY id` orders the accumulation row by row.
