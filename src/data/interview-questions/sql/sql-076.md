question: |
  Write a SQL query to generate a complete daily calendar table containing all dates for the current calendar year.
sampleData: |
  Output target: Daily timestamps from Jan 1 to Dec 31 of current year.
answer: |
  ```sql
  SELECT generate_series(
      DATE_TRUNC('year', CURRENT_DATE),
      DATE_TRUNC('year', CURRENT_DATE) + INTERVAL '1 year' - INTERVAL '1 day',
      INTERVAL '1 day'
  ) AS calendar_date;
  ```
explanation: |
  - `generate_series` creates continuous date intervals from start to end of year.
