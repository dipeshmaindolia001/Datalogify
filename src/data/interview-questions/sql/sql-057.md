question: |
  Write a SQL query to find all employees whose salary is exactly equal to their department average salary.
sampleData: |
  `employees` table: `id`, `name`, `department_id`, `salary`
answer: |
  ```sql
  SELECT e.*
  FROM employees e
  JOIN (
      SELECT department_id, AVG(salary) AS avg_salary
      FROM employees
      GROUP BY department_id
  ) d ON e.department_id = d.department_id AND e.salary = d.avg_salary;
  ```
explanation: |
  - Calculates average salary per department in subquery.
  - Joins back matching both department ID and exact salary equality.
