question: |
  Write a SQL query to identify products that experienced a price increase within the last 6 months using window functions.
sampleData: |
  `product_prices` table: `product_id`, `price`, `effective_date`
answer: |
  ```sql
  WITH PriceChanges AS (
      SELECT product_id, price, effective_date,
             LAG(price) OVER (PARTITION BY product_id ORDER BY effective_date) AS prev_price
      FROM product_prices
      WHERE effective_date >= CURRENT_DATE - INTERVAL '6 months'
  )
  SELECT DISTINCT product_id
  FROM PriceChanges
  WHERE price > prev_price;
  ```
explanation: |
  - Compares current price to previous price using `LAG()` over effective dates.
