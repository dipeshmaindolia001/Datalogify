question: |
  Write a SQL query to find employee IDs who have received more than 2 promotions.
sampleData: |
  `promotions` table: `employee_id`, `promotion_id`
answer: |
  ```sql
  SELECT employee_id, COUNT(*) AS promotion_count
  FROM promotions
  GROUP BY employee_id
  HAVING COUNT(*) > 2;
  ```
explanation: |
  - Groups promotions by `employee_id` and filters counts `> 2`.
