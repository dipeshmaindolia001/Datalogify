question: |
  Write a SQL query to find the difference in sale amount between current row and previous row partitioned by product.
sampleData: |
  `sales` table: `product_id`, `sale_date`, `amount`
answer: |
  ```sql
  SELECT product_id, sale_date, amount,
         amount - LAG(amount) OVER (PARTITION BY product_id ORDER BY sale_date) AS sales_diff
  FROM sales;
  ```
explanation: |
  - `LAG(amount) OVER (PARTITION BY product_id ORDER BY sale_date)` gets the preceding sale amount for the same product.
  - Subtracting this from current row's amount gives the step change.
