question: |
  Write a SQL query to concatenate all employee names in each department into a comma-separated string.
sampleData: |
  `employees` table: `department_id`, `name`
answer: |
  ```sql
  SELECT department_id, STRING_AGG(name, ', ') AS employee_names
  FROM employees
  GROUP BY department_id;
  ```
explanation: |
  - `STRING_AGG(name, ', ')` (PostgreSQL / SQL Server `STRING_AGG` or MySQL `GROUP_CONCAT`) aggregates text values into a single delimited string per group.
