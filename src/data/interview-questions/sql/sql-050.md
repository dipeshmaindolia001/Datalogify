question: |
  Write a SQL query to generate a 2x2 confusion matrix (True Positives, False Positives, True Negatives, False Negatives) from prediction evaluation logs.
sampleData: |
  `predictions` table: `actual`, `predicted`
answer: |
  ```sql
  SELECT
      SUM(CASE WHEN actual = 1 AND predicted = 1 THEN 1 ELSE 0 END) AS True_Positive,
      SUM(CASE WHEN actual = 0 AND predicted = 1 THEN 1 ELSE 0 END) AS False_Positive,
      SUM(CASE WHEN actual = 0 AND predicted = 0 THEN 1 ELSE 0 END) AS True_Negative,
      SUM(CASE WHEN actual = 1 AND predicted = 0 THEN 1 ELSE 0 END) AS False_Negative
  FROM predictions;
  ```
explanation: |
  - Uses conditional aggregation to count prediction classifications for machine learning model evaluation.
