question: |
  Write a SQL query to display total sales revenue per customer, showing $0 for customers who never placed an order.
sampleData: |
  `customers` table: `customer_id`, `name`
  `sales` table: `customer_id`, `amount`
answer: |
  ```sql
  SELECT c.customer_id, COALESCE(SUM(s.amount), 0) AS total_sales
  FROM customers c
  LEFT JOIN sales s ON c.customer_id = s.customer_id
  GROUP BY c.customer_id;
  ```
explanation: |
  - `COALESCE(SUM(s.amount), 0)` substitutes $0$ for `NULL` values produced by unmatched left joins.
