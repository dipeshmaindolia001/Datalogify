question: |
  Write a SQL query to get the second highest salary from the `Employee` table. If there is no second highest salary, the query should return `NULL`.
sampleData: |
  `Employee` table schema:
  | id | salary |
  |---|---|
  | 1 | 100 |
  | 2 | 200 |
  | 3 | 300 |
answer: |
  ```sql
  SELECT MAX(salary) AS SecondHighestSalary
  FROM Employee
  WHERE salary < (SELECT MAX(salary) FROM Employee);
  ```
explanation: |
  - The subquery `(SELECT MAX(salary) FROM Employee)` finds the highest salary.
  - The outer query finds the maximum salary that is strictly less than the highest salary, which gives us the second highest salary.
  - Using `MAX()` in the outer query handles the case where there is no second highest salary (e.g., if there is only one employee or if all employees have the same salary), returning `NULL` as required.
followUp: |
  How would you write this query to find the N-th highest salary (e.g., 3rd highest)?
  ```sql
  SELECT DISTINCT salary 
  FROM Employee 
  ORDER BY salary DESC 
  LIMIT 1 OFFSET N-1;
  ```
